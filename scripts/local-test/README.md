# 격리 로컬 테스트

작업 폴더: `to-high-fix` 저장소 루트. 확인한 버전은 Node.js 25.9.0, npm 11.12.1, Python 3.13입니다. Next.js의 최소 Node 버전은 20.9.0이며 Python 3이 필요합니다. 설치된 저장소 의존성을 사용하며 추가 설치는 필요하지 않습니다.

```sh
# 처음 실행하거나 코드를 변경한 뒤 빌드까지 다시 실행
python3 scripts/local-test/run.py restart --build

# 기존 빌드로 시작 / 상태 확인 / 종료
python3 scripts/local-test/run.py start
python3 scripts/local-test/run.py status
python3 scripts/local-test/run.py stop
```

- 홈: http://127.0.0.1:3102/
- 상담: http://127.0.0.1:3102/talk
- API 상태: http://127.0.0.1:3999/health

선택지를 클릭하거나 직접 입력해 보내면 `[로컬 모의 응답]`을 반환합니다. 입력·생각 중·답변 도착 상태, 후속 선택지, 종료·새 상담을 확인할 수 있습니다. `실패 테스트`를 보내면 의도적으로 503을 반환해 입력 복구를 확인할 수 있습니다. 위기 안내는 실제 서비스의 감지 로직을 사용합니다.

실제 Nest 상담 컨트롤러·서비스·입력 검증·취소·RAM 예산·요청 제한을 사용하고 모델 제공자만 모의 구현으로 교체합니다. 인증은 익명 테스트 전용이며 OAuth·계정·캐릭터·기억 저장 테스트를 지원하지 않습니다. 기존 데이터와 운영 API에 연결하지 않으며 Mongo가 필요하지 않습니다. 이것은 실제 모델 응답이나 전체 운영 API 검증이 아닙니다.

런처는 허용한 기본 시스템 환경만 전달합니다. 기존 `.env`나 자격 증명을 로드·복사하지 않습니다. 로컬 전용 `NEXT_PUBLIC_API_URL`, `NEXT_TELEMETRY_DISABLED`, `NODE_ENV`, `TO_HIGH_LLM_DAILY_REQUEST_LIMIT`을 설정하며 운영 설정은 바꾸지 않습니다. 로컬 모의 요청 예산은 일100회/프로세스이고 생성 요청에는 기존 분당 제한이 적용됩니다. 모든 서버는 loopback에만 바인딩하고 외부 연결·모델 fetch는 차단합니다.

실제 AI를 사용하려면 별도 승인과 제공자 자격 증명·예산 검토가 필요합니다. 이 런처에는 실제 AI로 전환하는 옵션이 없습니다. API 키를 README나 로그에 입력하지 마세요.

로그와 소유 프로세스 정보는 Git에서 제외된 `scripts/local-test/.runtime/`에 남습니다. 로그에는 상담 본문을 기록하지 않습니다. 포트가 다른 프로세스에 점유되어 있으면 런처는 중단하며 해당 프로세스를 종료하지 않습니다. Mac이 잠자기 상태이거나 재부팅되면 다시 실행해야 합니다. 휴대폰에서 이 loopback 주소에 직접 접속할 수는 없습니다.
