# 위로 제품 원칙

## 서비스

위로는 처음부터 마음을 길게 설명하기 어려울 때, 버튼으로 이야기를 시작할 수 있는 서비스입니다. 기본 AI 상담 캐릭터는 레비입니다. 대화의 깊이와 속도는 사용자가 정합니다.

현재 공개 기능은 [구조 문서](architecture.md)에, 사용자가 보는 소개는 [README](../README.md)와 [랜딩 화면](../apps/web/src/components/landing/wirocare-landing.tsx)에 있습니다.

## 승인된 카피

| 위치 | 문구 |
| --- | --- |
| 첫 화면 제목 | 레비에게 마음을 털어놔보세요 |
| 첫 화면 설명 | 내 상황을 이해하는 AI 상담사 '레비' |
| 주요 버튼 | 레비와 대화 시작하기 |
| 시작 안내 | 가입 없이 시작할 수 있어요 |
| 소개 제목 | 레비에게는 일일이 설명해주지 않아도 괜찮아요! |
| 소개 설명 | 지금 마음과 가까운 버튼을 골라보세요. / 마음이 열리면, 그때 조금 더 들려주세요. |
| 대화 안내 카드 | 버튼을 클릭해서 시작하고, 간편하게 대화를 이어가요 |
| 저장 안내 카드 | 대화는 저장하지 않아요 |
| 마지막 초대 | 지금, 레비와 이야기해볼까요? |
| 직접 입력 열기 | 다른 마음이 있어요 |

슬래시는 문장 구분을 설명하기 위한 표기입니다. 화면에는 두 문장을 줄바꿈으로 표시합니다. 장식용 가운데 점·구분선이나 새 표어를 서비스명에 붙이지 않습니다. 문구를 바꿀 때는 실제 사용 위치와 사용자의 확인 내용을 함께 반영합니다.

## 이용 경험

- 가입과 개인정보 입력 없이 대화를 시작합니다. 공개 채팅에 정해진 턴 수의 로그인 유도를 추가하지 않습니다.
- 선택지만 눌러도 이어갈 수 있어야 합니다. 긴 설명이나 직접 입력을 기본 행동으로 요구하지 않습니다.
- 직접 입력은 사용자가 원할 때 펼칩니다. 선택지를 누르거나 답변을 받았다는 이유로 모바일 키보드를 열지 않습니다.
- 질문은 필요할 때 하나씩 합니다. 이미 말한 내용을 반복해서 묻거나 고정된 공감·분석·조언 단계를 채우지 않습니다.
- 위로는 사용자가 실제로 말한 상황과 감정에서 출발합니다. 말하지 않은 고통·관계·원인을 덧붙이거나 AI의 해석을 사실로 단정하지 않습니다.
- 사용자가 경청·정리·방법을 요청하면 그 범위를 존중합니다. 특정 버튼을 눌렀다고 숨은 모드로 바꾸지 않습니다.
- 대화를 마치거나 더 말하지 않을 선택을 존중합니다. AI만이 이해한다는 표현이나 독점적 관계를 약속하지 않습니다.

## 신뢰와 데이터

레비는 AI 상담 캐릭터로, 진단이나 치료나 사람 상담사를 대신하지 않습니다. 사람 상담사·의료인으로 가장하거나 질환·약물에 대한 의료 판단을 제공하지 않습니다.

공개 채팅 원문과 일시 요약은 서비스 DB에 저장하지 않고 현재 화면의 메모리에서만 유지합니다. 답변 생성에 필요한 서버·AI 제공자의 처리와 별도 보관 정책은 정확하게 안내합니다. 완전한 공급자 무보관이나 완전한 익명성을 근거 없이 약속하지 않습니다.

화면·평가 예시에는 실제 사용자 대화를 사용하지 않습니다. Sentry 등 관측 기능을 변경할 때도 대화 내용·개인정보를 보내지 않는 경계를 유지합니다.

현재 공개 채팅에는 키워드 기반 고정 위기 안내 UI가 없습니다. 이것을 복원할 의무로 적힌 과거 문서를 현재 요구사항으로 적용하지 않습니다. 모델의 기본 안전 경계는 별도로 유지합니다.

## 문서의 역할

README는 이용자가 서비스를 이해하고 레비를 만나도록 돕는 소개입니다. 설치·빌드·환경변수·구현 상세는 [개발 가이드](development.md)와 관련 기술 문서에 둡니다.

기능을 설명할 때 공개된 기능과 코드에만 남은 기능을 구분합니다. 화면 변경은 시안을 보여주고 확인받으며, 이미 승인한 내용을 다시 확인하느라 작업을 멈추지 않습니다.
