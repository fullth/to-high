## 버튼을 클릭해서 시작하고, 간편하게 대화를 이어가요

말하기 어려운 날은 선택지를 눌러요. 직접 입력해 이야기할 수도 있어요.

레비의 이야기를 읽고, 지금 마음과 가까운 답을 골라주세요. 더 들려주고 싶은 마음이 있다면 **‘다른 마음이 있어요’**를 눌러주세요.

## 대화는 저장하지 않아요

대화는 이 화면에만 남아요. 새로고침하거나 화면을 떠나면 사라져요.

답변을 위해 대화는 서버와 AI 제공자가 처리해요. 서비스 데이터베이스에는 상담 원문을 저장하지 않으며, 제공자 측 보관은 해당 정책과 설정에 따라요.

[개인정보 처리 안내](https://www.wirocare.com/privacy)

레비는 AI 상담 캐릭터로, 진단이나 치료나 사람 상담사를 대신하지 않아요.
